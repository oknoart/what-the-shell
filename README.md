# Raup 1966 · 3D Shell Morphospace Generator

An interactive, browser-based implementation of **David M. Raup's 1966 coiled
shell morphospace** model. Drag three parameters and watch a logarithmic shell
grow in real time — from flat ammonites to tall tower shells to open ram's
horns.

Built with plain **Vite + Three.js** (no UI framework).

**Live demo:** <https://oknoart.github.io/what-the-shell/>

## Background

In *"Geometric analysis of shell coiling: general problems"* (Journal of
Paleontology, 1966), Raup showed that a remarkable variety of coiled shell
forms can be generated by varying just three parameters on a logarithmic
helicospiral:

| Symbol | Meaning | Range |
| --- | --- | --- |
| **W** | Whorl expansion rate — radial growth per full revolution | 1.1 – 10 |
| **D** | Normalized distance of the generating curve from the coiling axis | 0 – 0.85 |
| **T** | Vertical translation rate along the coiling axis | 0 – 6 |

The generating curve (a circle) grows as `a(θ) = a₀ · kᵟ`, where
`k = W^(1/2π)`, sits at distance `r_c = a · (1+D)/(1−D)` from the axis, and
rises by `z_c = T · r_c`.

## Getting started

```bash
npm install
npm start
```

`npm start` launches the Vite dev server and opens the viewer in your browser
(usually <http://localhost:5173>).

Other scripts:

```bash
npm run dev      # dev server, no auto-open
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Presets

| Preset | W | D | T |
| --- | --- | --- | --- |
| Ammonite (flat coil) | 2.2 | 0.15 | 0.0 |
| Turritella (tower screw) | 1.35 | 0.10 | 4.5 |
| Classic snail | 2.0 | 0.25 | 1.5 |
| Ram's horn (open coil) | 1.8 | 0.65 | 0.8 |
| Abalone (flared) | 8.0 | 0.10 | 0.4 |

> The "Abalone" preset is stylized: a real abalone is a low-spired, ear-shaped
> shell, so the label is illustrative rather than taxonomically exact.

## Controls

- **Sliders** update the mesh live (coalesced to one rebuild per animation
  frame).
- **Presets** jump to well-known shell forms.
- **Wireframe** toggles the mesh wireframe.
- **Auto-rotate** runs a turntable.
- **Orbit controls**: drag to rotate, right-drag to pan, scroll to zoom.

## Project layout

```
index.html              UI shell and control panel
style.css               Dark glassmorphism styling
src/math/raupGeometry.js  Pure Raup parametrization → typed arrays
src/scene/shellViewer.js  Three.js scene, lighting, material, OrbitControls
src/ui/controls.js        Slider / preset / toggle wiring
src/main.js               Entry point
```

## Notes

- Generated geometry is normalized to a unit bounding sphere, so every preset
  is framed consistently. An adaptive growth cap keeps high-`W` shells stable.
- Previous geometries are disposed on each rebuild to avoid GPU memory growth.
